# Frozen KEGG mapping

`kegg_mmu_snapshot_2026-09-15.rds` contains the mouse pathway-to-gene and pathway-to-name mappings retrieved through the KEGG API on 15 September 2026. It is included solely to reproduce the academic analysis reported here.
