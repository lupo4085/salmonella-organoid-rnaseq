 Bulk RNA-seq analysis of Salmonella-infected Apcmin/+ tumour organoids

Analysis code accompanying the MSci placement report:

**Characterisation of host inflammatory responses to intracellular and extracellular attenuated *Salmonella* Typhimurium in *Apc*^min/+^ tumour organoids**

University of Glasgow | Cancer Research UK Scotland Institute, 2026

## Overview

This notebook performs differential expression analysis and pathway enrichment analysis on bulk RNA-seq data from *Apc*^min/+^ murine intestinal tumour organoids infected with attenuated *Salmonella* Typhimurium (STm^ΔAroA^), in the presence or absence of methyl-β-cyclodextrin (MβCD). The analysis compares host transcriptional responses under four conditions: non-treated (NT), MβCD-treated, intracellular infection (STm), and extracellular-restricted infection (STm+MβCD).

## Contents

- `Salmonella_Mouse.ipynb` — R notebook containing all analysis steps

## Analysis steps

1. **Differential expression analysis** using DESeq2 with shrunken log₂ fold change estimates
2. **Volcano plots** for intracellular and extracellular infection conditions
3. **Gene set enrichment analysis (GSEA)** using clusterProfiler with KEGG pathway database
4. **NF-κB pathway heatmap** of differentially expressed genes across all four conditions

## Dependencies

- R ≥ 4.5
- DESeq2
- clusterProfiler
- org.Mm.eg.db
- ggplot2, ggrepel, ggsignif
- pheatmap
- tidyverse
- VennDiagram

## Input data

The notebook reads `coldata_ms.csv` (sample metadata and count matrix). Raw RNA-seq data were generated by G. Mackie and are not included in this repository.

## Figures generated

The scripts generate figures corresponding to Figure 1 in the placement report (volcano plots, KEGG GSEA bar plots, and NF-κB pathway heatmap).
